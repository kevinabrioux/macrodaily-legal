# macrodaily-legal

Pages légales publiques de l'app iOS **MacroDaily**, publiées via GitHub Pages.

- Politique de confidentialité (EN + FR) : https://kevinabrioux.github.io/macrodaily-legal/
- Assistance / support (EN + FR) : https://kevinabrioux.github.io/macrodaily-legal/support/ — champ « Support URL » d'App Store Connect

L'URL de la politique est celle renseignée dans le champ « Privacy Policy URL » d'App Store Connect
et dans l'écran Profil de l'app : elle doit rester stable. Même règle pour l'URL de support.

Le repo est public parce que GitHub Pages l'exige ; il ne contient aucun code de l'app.
Toute modification de `index.html` est en ligne après quelques secondes.
